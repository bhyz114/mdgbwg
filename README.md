## 游戏结局流程图

当前版本共有 6 个结局：基础结局 3 个、真结局 1 个、隐藏结局 2 个。

```mermaid
flowchart TD
    S["序章：历史之眼触发"] --> L["澜视角：棂盟约"]
    L -->|答应粟部族| B["南坡封锁，鱼部预谋增强"]
    L -->|拒绝粟部族| O["南坡开放，棂可能泄密"]

    B --> J["葭视角：神谕选择"]
    O --> J
    J -->|告知姥姥| G["鸟部提前布防"]
    J -->|告知众人| P["公开指控：梦到 / 偷听 / 无法解释"]
    J -->|谁都不说| N["无预警赴典"]
    P -->|至少两项核心证据被采信| G
    P -->|证据不完整| U["预警不完整"]
    P -->|指认、扣押或处置澜姬使预谋继续| X["鱼部预谋未切断"]

    G --> C["大典混战：终极抉择"]
    N --> C
    U --> C
    X --> C
    C -->|救葭| F["葭抵达花部族"]
    C -->|救姬| K["姬误杀玩家"]
    C -->|都不救 / 迟疑| A["乱箭杀死玩家"]
    F -->|返回救姬| R["返场途中中箭"]
    F -->|留在花部族| D["伤口感染死亡，进入坞线候选"]

    K --> E["基础结局判定"]
    A --> E
    R --> E
    D --> E
    E -->|南坡封锁 / 鱼部预谋继续 / 未救葭| EF["ENDING 01：鱼部崛起"]
    E -->|南坡开放 + 鸟部预警 + 救葭| EB["ENDING 02：代价高昂的胜利"]
    E -->|南坡开放 + 预警不完整 + 双方未决胜| EA["ENDING 03：灰烬之歌"]

    EB --> T{"满足真结局条件？"}
    T -->|现代许诺、远古承诺、回溯与纹魂达标，葭和陶瓶受保护| ET["TRUE ENDING 04：千年重逢"]
    T -->|不满足| EB2["保留 ENDING 02"]
    EB2 --> W{"满足坞线严格门槛？"}
    W -->|救葭、留在花部族并感染死亡| WX["坞线"]
    W -->|不满足| END["结算"]
    WX -->|支持复仇| EC["HIDDEN ENDING 05：众欲覆辙"]
    WX -->|劝葭打破循环| EI["HIDDEN ENDING 06：融冰之土"]
```

结局判定优先级：

`众欲覆辙` → `融冰之土` → `千年重逢` → `灰烬之歌` → `代价高昂的胜利` → `鱼部崛起`

公开指控的四项核心证据：白灰残泥、南坡荆棘、姬的骨饰、粟部族盟约。
